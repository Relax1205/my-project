Файл-инструкция для сервиса HelpDesk.Results
Этот документ раздаётся через маршрут /files/readme с использованием Results.File().
Путь к файлу жёстко задан в коде и указывает на защищённую директорию wwwroot/files.
Эндпоинт не принимает пути из пользовательского запроса, что исключает уязвимость обхода каталогов (Path Traversal).
Файл предназначен для демонстрации безопасной отдачи статических ресурсов в ASP.NET Core Minimal API.
